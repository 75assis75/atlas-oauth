A.T.L.A.S.

Assistente pessoal de inteligência artificial para uso local.

O A.T.L.A.S. é um projeto pessoal que integra recursos de assistência por voz, automação residencial, monitoramento de dispositivos e consulta e gerenciamento de informações autorizadas pelo usuário.

Integração com o Gmail

Com autorização expressa do titular da conta, o A.T.L.A.S. utiliza a API do Gmail para consultar mensagens, apresentar resumos e executar ações de gerenciamento e envio de e-mails solicitadas pelo usuário. A autorização pode ser revogada nas configurações de segurança da Conta Google.

O uso de informações recebidas das APIs do Google observa os requisitos de uso limitado dos dados do usuário, incluindo os requisitos aplicáveis ao Gmail.

Privacidade

Leia a Política de Privacidade para entender quais dados podem ser acessados, utilizados e armazenados.
